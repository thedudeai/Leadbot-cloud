Team

Who can sign in, what they can see, and which Zoho user they are. A person pinned to a Zoho owner only ever browses and profiles the leads they own in the CRM; an admin, or anyone marked "sees all", browses the whole org.

Segments

Saved targeting. Each one is a Zoho COQL where clause. Three org quirks worth remembering: no aggregates, three or more criteria need explicit parentheses ((a and b) and c), and Owner = '<id>' works while Owner.id does not.

Setup

Lead Bot does none of the work itself. The server launches Claude Code for each lead, and Claude does the searching and verifying through the company's connectors. This screen is where you confirm that link is live. Only admins see it.

Zoho connection
